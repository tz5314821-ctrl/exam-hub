# 春招研习社 · Spring Exam Lab

面向 2027 春招备考的独立笔试练习网站，覆盖国企通用能力、国有大行、石油能源、人寿保险。

## 当前内容

- 30 道原创练习，均附选项、答案与解析；不宣称来自企业真题。
- 专项与关键词筛选、收藏、即时判分、错题复盘。
- 10 题 / 10 分钟自测，统一交卷；这是练习模式，不代表任何企业考试结构。
- 本机浏览器保存学习记录，可导出或合并导入 JSON；无账号和云同步。
- 11 条公开资料与检索入口，明确区分官方公告、第三方线索、付费文档和待核验入口。

## 运行

需要 Node.js 22 或以上，无第三方依赖。

```sh
npm test
npm run build
npm start
```

打开 http://127.0.0.1:4173 。静态文件在 dist/；也可将构建结果部署到任意静态服务器。

## GitHub Pages

工作流 `.github/workflows/pages.yml` 在 main 更新时运行校验、构建和部署。在仓库 Settings → Pages 中将 Source 设置为 GitHub Actions；若工作流有权自动启用，则不需手动设置。

预期地址：https://tz5314821-ctrl.github.io/exam-hub/ （以实际部署成功为准）

## 题目与资料维护

题目与来源在 `data.js`。原创题标注 `kind: 原创练习`、`year: null`，不要改成未经核验的企业或年份。导入真题前应记录原始链接、企业、考试年份、回忆/官方属性、使用许可、答案复核和核验日期。付费购买不自动取得转载许可。

检索快照为 2026-11-22：GitHub、知乎、抖音、微博及付费文档已发现公开线索；X 与闲鱼本轮未找到可核验的具体内容，仅提供入口。未进行登录后全站搜索、付费购买、视频转写或批量抓取。2026 春季公告是历史参考，不能当作 2027 春招通知。

欢迎通过 Issues 提交勘误或有分享权限的资料链接。不得提交正在进行的考试内容、他人个人信息或无权传播的资料。

## 验证与限制

`npm test` 校验题目结构、答案索引、专题题量和来源状态，不能替代人工内容审校。浏览器禁用存储时记录可能无法持久化；刷新会丢失正在进行的自测，既有学习记录保留。字体使用可选 Google Fonts，加载失败时使用系统中文字体。
